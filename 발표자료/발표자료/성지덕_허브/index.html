01OVERVIEW · 개요

어디로 떠나는 여행일까

성지덕은 작품을 고르면 지도에 성지 스팟을 띄우고, 기간·예산·출발지에 맞춰 AI가 성지 중심 루트를 생성하는 여행 플래너예요. 대표 데모는 러브라이브! 뮤즈, 기간은 2026.06.29–07.10.

🎯 목표

필수 5대(회원·영속화·UI·AI·관리자 통계)를 결함 없이 동작 + HTTPS 배포까지.

🧱 스택

Spring Boot · Security · JPA · LangGraph · PostgreSQL · Docker · GitHub Actions.
