# 성지덕 시연 런북 (팀 공유용 · 발표 당일)

> 시연 주소: **https://holymoly.cloud** · 슬라이드 7~13 구간에서 라이브 시연
> 계정 비밀번호는 팀 채널 공유 메모 참조 (여기엔 안 적음)

---

## 발표 전 준비 (담당 1명, ~15분 전)

| 순서 | 할 일 | 이유 |
|---|---|---|
| 1 | 사이트 접속 → **러브라이브 클릭 → 지도 뜨는지** 확인 | 예열 확인 (즉시 안 뜨면 1분 기다렸다 재클릭) |
| 2 | 러브라이브의 **"여행자들이 검증한 코스" 섹션 열기** | 검증 캐시 6시간 TTL — 발표 직전 재예열 필수 |
| 3 | **시연용 일반 계정 로그인 탭** + **관리자 계정 로그인 탭** 각각 준비 | 결제 오퍼는 로그인+저장 일정 필요 / 13번 관리자 데모 |
| 4 | 3D 시사회 한 번 재생 | GLB 첫 로드 캐싱 (현장 와이파이에서) |
| 5 | 팀원 전원 사이트 한 바퀴 (작품 클릭·일정 생성) | 이벤트가 쌓여 관리자 대시보드·Grafana 그래프가 살아 보임 |
| ⚠️ | **발표 전까지 EC2·dev 머지 금지.** 컨테이너 재시작했다면 NPM도 재시작 | 캐시 소실·502 방지 |
| 🔴 | **발표 ~15분 전 AI 모델 승격 (필수!)**: EC2에서 `cd ~/deploy && sudo sed -i 's/^AI_MODEL=.*/AI_MODEL=gpt-5.1/' .env && sudo docker compose up -d ai-service` | 평소엔 gpt-4o-mini로 내려놔서 구경꾼들의 GPT 낭비 방지 — 시연 품질(제목·재조정)은 5.1이 필요 |

## 시연 클릭 순서 (슬라이드 7~13)

### ⑦ 작품 선택 → 지도 (0:50)
1. holymoly.cloud 접속 (랜딩 지구본)
2. 작품 그리드에서 **러브라이브!** 클릭
3. 지도에 성지 33곳 핀 확인 — "15작품 성지 500곳" 멘트

### ⑧ GPT 설명 & 검증 코스 (1:15)
1. 성지 카드 하나 클릭 → **한국어 설명·체류시간·현장 팁** 보여주기
2. 스크롤 → **"여행자들이 검증한 코스"** 섹션 → 🥇 코스 A (칸다묘진→UDX→타케무라)
3. 출처 블로그 링크 하나 클릭해 실제 후기 잠깐 보여주기 (새 탭)

### ⑨ AI 일정 & 재조정 (1:10)
1. 스팟 4~5개 담기 (검증 코스 스팟 포함) → **일정 생성** (약 10초 — 기다리는 동안 멘트)
2. Day별 타임라인 확인 — 검증 코스가 뼈대로 들어간 것 언급
3. 재조정 입력창에 **"2일차는 여유롭게"** 입력 → 재생성

### ⑩ 주변 볼거리 (0:50)

2. 닫고 → 주변 볼거리 테마 칩 → 맛집 하나 **"+ 일정에 담기"** → 다시 짜기로 반영되는 것 보여주기

### 마이페이지 가서 시사회 버튼 클릮!!
마이페이지 클릭해서 저장된 일정 시사회보기 버튼 클릭
1. **시사회 보기** 클릭 → 월드맵→일본 줌인→경로 부감 시네마틱


### ⑪ 예약 · 결제 (0:40)
1. (로그인 탭에서) 일정 **저장** → 예약·결제 섹션 → 항공 ₩230,000 / 숙소 ₩180,000 오퍼
2. Toss 결제창까지만 열고 닫기 (실결제 X)

중요: 마이페이지 들어가서 생성된 일정에 

### ⑬ 관리자 대시보드 (0:50)
1. (관리자 탭에서) 헤더 **관리자** 메뉴 → 대시보드
2. 일자별 사용자·생성 비율·인기 작품 도넛(자동재생) 보여주기
3. 새 탭: **holymoly.cloud/grafana** → "성지덕 서비스 통계" 대시보드 잠깐 보여주기

## 문제 발생 시 (플랜 B)

| 증상 | 대응 |
|---|---|
| 지도가 "불러오지 못했어요" | 그 작품 다시 클릭 (첫 생성 지연). 데모는 예열된 러브라이브로 |
| 사이트 전체 502 | 발표자는 **백업 녹화본**으로 전환, 뒤에서 EC2 `docker compose restart npm` |
| 일정 생성이 30초+ | AI 폴백 가능성 — 결과는 나오니 그대로 진행, "피크 시 폴백도 준비돼 있다" 멘트로 전환 |
| 결제 오퍼 안 보임 | 로그인 확인 + 일정 **저장** 눌렀는지 확인 |
| 관리자 메뉴 안 보임 | 관리자 계정으로 로그인했는지 확인 |
