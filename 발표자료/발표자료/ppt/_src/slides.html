[00:00.00] 🔒 describe-lock 획득 — GPT 호출 시작
[00:00.01] content=1 (동시 #2) → lock 대기… # StrictMode
[01:06.10] ✅ GPT 완료 (33 spots) — 캐시 저장 ← 66.10s
[01:06.15] content=1 (대기 #2) → 캐시 HIT 0.05s ← GPT 재호출 없음

TROUBLESHOOTING · DEPLOY

ai-service 부팅 실패 — 원인은 Dockerfile 한 줄

증상
컨테이너 crash 반복
Traceback ...
File "/app/main.py", line 10
ModuleNotFoundError:
No module 'route_graph'
describe·일정·검증 전부 미도달 → 폴백
원인
COPY가 파일을 개별 나열
main.py는 route_graph를
import 하는데 Dockerfile은
그 파일을 복사 목록에서 누락
로컬은 통과 → 배포에서만 터짐
해결 · ai #19
전체 모듈 복사
COPY requirements.txt .
- COPY main.py ... trip_graph.py
+ COPY *.py ./
새 모듈 추가 시 재발 방지
💡 교훈 — 개별 나열 COPY는 새 모듈마다 배포에서 조용히 깨진다. 그리고 통합 지점은 실제 통신으로 확인(단위테스트가 못 잡음).
