TROUBLESHOOTING · DEPLOY

ai-service 부팅 실패 — 원인은 Dockerfile 한 줄

증상

컨테이너 crash 반복

Traceback ...
  File "/app/main.py", line 10
ModuleNotFoundError:
 No module named 'route_graph'

describe·일정·검증이 전부 ai-service 미도달 → 조용히 폴백

원인

COPY가 파일을 개별 나열

main.py는 route_graph를
import 하는데, Dockerfile은
그 파일을 복사 목록에서 누락
→ 이미지에 route_graph.py 없음

로컬은 파일이 있어 통과 → 배포에서만 터짐

해결 (ai #19)

전체 모듈 복사

COPY requirements.txt . - COPY main.py ... trip_graph.py ./ + COPY *.py ./ EXPOSE 8000

새 모듈 추가 시 재발 방지

💡 교훈: 개별 파일 나열 COPY는 새 모듈이 늘 때마다 배포에서 조용히 깨진다. 그리고 배포 후 이미지 Created 시각을 최신 CI 빌드와 대조(stale 이미지 방지).
