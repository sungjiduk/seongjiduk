# ADR-0004. AI 모델 선택·프롬프트 정책

- 상태: 승인 (Accepted)
- 날짜: 2026-07-07

## 맥락
성지 "장면 설명" 품질은 제품 체감의 핵심. gpt-4o-mini / gpt-4o / gpt-5.5를 같은 요청(러브라이브 성지)으로 실측 비교했다.

## 실측 비교 (describe, 동일 프롬프트·동일 스팟)

| 모델 | 속도(실측) | 품질 특성 | 비용* |
|---|---|---|---|
| gpt-4o-mini | 3곳 ~5초 | 어느 신사에나 붙는 일반론("소중한 추억을 쌓는 장소") | $0.15 / $0.60 |
| **gpt-4o (기본)** | 3곳 ~8초, 34곳 ~66초 | 작품 지식으로 실제 그라운딩(칸다묘진=결성/연습 장면), 서비스 카피로 자연스러움 | $2.50 / $10.00 |
| gpt-5.5 | 3곳 ~27초 (reasoning) | **덕후 전문가급 정확도** — "μ's의 훈련 계단", "노조미와의 인연"(실제 무녀 설정)까지. 단 라이브 경로엔 너무 느림 | 공식 요금표 확인 필요** |

\* 1M 토큰당 입력/출력, 2025 공시가 기준 — 청구 전 최신 요금표 확인.
\*\* gpt-5.5(2026-04 출시)는 요금 미확인 상태로 기록. 도입 전 확인.

## 결정
1. **라이브 경로 기본 모델 = `gpt-4o`** (env `AI_MODEL`). 속도·품질·비용의 균형점. 코드 기본값은 `gpt-4o-mini` 유지(키 없는 CI 저비용).
2. **gpt-5.5는 사전 생성(pre-warm) 전용 후보**: 임포트 직후 백그라운드로 설명을 미리 생성·캐시하는 구조가 생기면 그때 투입(사용자 대기 없음 → 느려도 최고 품질). gpt-5.x는 `AI_TEMPERATURE=1` 필요.
3. **프롬프트 3원칙** (실측으로 도출, ai #2):
   - **작품 지식 활용 허용**: "주어진 정보에만 근거" 식 과잉 제약은 상위 모델의 지식을 봉인(5.5가 헤징 문구만 생성) → "네가 아는 지식을 적극 활용하되, 불확실한 세부(대사·영업시간·요금)만 생략"으로 완화.
   - **메타 코멘트 금지**: "정보가 제공되지 않았으므로…" 같은 문구가 사용자 화면에 그대로 노출됨 → 명시적 금지.
   - **출력 언어 고정**: 일본어 장소명에 끌려 설명 전체가 일본어로 드리프트(실측) → "반드시 한국어, 고유명사만 원어 허용, 일본식 마침표(。) 금지" 명시.

## 결과 / 영향
- 브라우저 전수 검증: 34/34 한국어 설명, 메타 코멘트·`。` 0건.
- 교훈: **프롬프트 제약은 모델 능력에 맞춰 조정해야 한다** — 같은 프롬프트가 mini에겐 안전장치, 5.5에겐 족쇄였다.
