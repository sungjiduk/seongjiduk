# 16. 관리자 대시보드 설계 (분석 시각화)

> 관리자 통계 API(`/api/admin/major/*`)를 소비해 스케치대로 대시보드 시각화.
> 팀원 백엔드 계약 기준 **프론트 선구현 + devMock**. 결정일: 2026-07-09.

## 0. 확정 결정
- **차트: Recharts** (React 19 호환, 선·영역·도넛 선언적·애니메이션). 피어충돌 시 chart.js 폴백.
- **TOP 도넛: 날짜 스크러버/애니메이션** (values[날짜] 순회, 슬라이더 + 자동재생).
- 새 관리자 뷰 + 로그인 헤더 진입. 관리자 아니면 API 403 → "권한 없음" 카드.
- 백엔드 `/api/admin/major/*` 미존재 → devMock으로 UI 완결, 머지 후 실연동.

## 1. 백엔드 계약 (팀원 제공)
전부 `{duration, date[, count]}` 요청. `duration ∈ {week, month, year}`(= 7일/30일/365일).

| 경로 | 요청 | 응답 |
|------|------|------|
| POST `/api/admin/major/user` | `{duration, date}` | `{values:number[], dates:string[]}` |
| POST `/api/admin/major/rate` | `{duration, date}` | `{values:number[], dates:string[]}` |
| POST `/api/admin/major/content` | `{duration, date, count}` | `{values: [ [ [name,count,ratio], … ], …날짜별 ], dates:string[]}` |
| POST `/api/admin/major/spot` | `{duration, date, count}` | 위와 동일 형태 |

- user = 일자별 사용자 수, rate = 생성/재생성 비율.
- content/spot `values[i]` = `dates[i]` 시점의 TOP N `[작품명, 건수, 비율]` 배열.
- ⚠️ 응답에 **목표값 없음** → 사용자 선그래프의 "목표선"은 프론트에서 평균 기준 ReferenceLine으로 대체(추후 API에 목표 필드 생기면 교체).
- 인증: 관리자 JWT(`auth:true`). 비관리자 → 403.

## 2. 데이터 계층 (`src/api.ts`)
```ts
export type AdminDuration = 'week' | 'month' | 'year'
export interface AdminSeries { values: number[]; dates: string[] }
export type AdminTopEntry = [name: string, count: number, ratio: number]
export interface AdminTopSeries { values: AdminTopEntry[][]; dates: string[] }
fetchAdminUser(duration, date): Promise<AdminSeries>
fetchAdminRate(duration, date): Promise<AdminSeries>
fetchAdminContent(duration, date, count): Promise<AdminTopSeries>
fetchAdminSpot(duration, date, count): Promise<AdminTopSeries>
```
전부 POST `body:{duration,date[,count]}`, `auth:true`.

## 3. 컴포넌트 (`src/admin/`)
- `AdminDashboard.tsx` — 상단 기간 토글(7일/30일/365일 → week/month/year) + 날짜(기본 오늘, `<input type=date>`). 선택 변경 시 4개 병렬 fetch. 로딩·에러·**403(권한없음)** 상태. 레이아웃(스케치): 사용자 선그래프 → 생성/재생성 영역 → TOP 작품 → TOP 성지.
- `SeriesChart.tsx` — `{data:AdminSeries, kind:'line'|'area', label, goal?:boolean}`. line=사용자수(+평균 목표선 ReferenceLine), area=생성/재생성. Recharts `LineChart`/`AreaChart` + `XAxis(dates)`+`Tooltip`.
- `TopDonut.tsx` — `{data:AdminTopSeries, title}`. 현재 날짜 인덱스 state, 슬라이더(range) + ▶자동재생(setInterval, 언마운트 정리). `values[idx]`로 Recharts `PieChart`(도넛=innerRadius) + TOP 리스트(이름·건수·비율%). 인덱스 바뀌면 Recharts 트랜지션 애니메이션.
- `admin.css` — 기존 토큰(카드·--rail·--hanko·--ink 등). 섹션 카드 그리드.

## 4. 진입·인증 (`src/App.tsx`, `src/auth.ts`)
- `View` 유니온에 `{name:'admin'}` 추가. 로그인 시 헤더에 "관리자" 링크(마이페이지 옆).
- 관리자 여부는 프론트가 확실히 모름 → 링크는 로그인 시 노출, 대시보드가 API 403이면 "관리자 전용" 안내 카드. (JWT role 디코드는 후속 최적화.)
