- 필수: 회원/OAuth, 데이터 영속화, 접속 가능한 UI, AI 에이전트, 관리자 통계
- 필수 기술: Java 25+, Spring(Boot/Security/Data), LangGraph, DB 1종, Docker/Compose, GitHub Actions, 클라우드 1종, HTTPS
- UI/UX는 평가 대상 아님 → **기능 정상 동작이 최우선**
