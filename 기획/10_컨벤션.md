# 10. 컨벤션 정의 문서 (제출물)

## Git
- 브랜치: `main` / `develop` / `feature/xxx` / `fix/xxx`
- 커밋: Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`, `chore:`, `test:`)
- PR: 리뷰 1인 이상 승인 후 머지

## 코드 (Java/Spring)
- 패키지 구조: (layered / domain 중 택)
- 네이밍: 클래스 PascalCase, 메서드/변수 camelCase, 상수 UPPER_SNAKE
- DTO/Entity 분리, Lombok 사용 범위 합의
- 포매터/린터: (예: Spotless, Checkstyle)

## API
- REST 명명: 복수 명사, 소문자, kebab/스네이크 합의
- 응답/에러 포맷 통일 (`05_API_명세.md` 참조)

## 문서
- 날짜 절대표기(YYYY-MM-DD), 결정은 ADR
